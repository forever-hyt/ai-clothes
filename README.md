# 衣搭灵感 · 安全演示

真实 AI、数据库、注册及支付尚未接入。

## 工作台与语言

顶部“创作工作台”和“隐私与安全”是独立切换按钮，手机端同样可见。页面内切换保留当前素材，并支持浏览器返回。简体中文 / English 切换覆盖导航、工作台、隐私、条款、登录及错误提示；只在浏览器保存语言偏好。

本地演示无需登录：仅使用内置成年人物插画与内置衣橱素材，单独确认本地处理授权及成年、非色情用途后可制作搭配板、查看原图并下载 PNG。自上传素材仅本地查看，审核未接入前禁止生成与导出。图片仅在浏览器处理，搭配板不是 AI 换装结果。本地功能不消耗服务器演示配额。真实衣服替换入口关闭。服务器接口仍执行登录、独立上传授权、非色情用途确认及格式/空白验证，但因内容审核未配置拒绝输出任何图片。

## 配置登录账号

运行 `npm run setup-login`，在本机输入用户名和密码（密码隐藏，至少 12 位）。脚本仅将用户名和加盐密码哈希写入已被 Git 忽略的 `.env.local`，不会保存明文密码，并保留其他环境配置。配置后重启本地服务。不要将密码发送到聊天或提交到仓库。

公网部署需要将 `LOGIN_USERNAME` 与 `LOGIN_PASSWORD_HASH` 配置到平台服务器环境变量，并设置正确的 HTTPS `APP_ORIGIN` 后重新部署。未配置账号时，页面明确说明登录尚未开放；本地演示继续可用。登录后客户端会验证会话，Cookie 未保存时显示说明。

检查：`npm run test`、`npm run lint`、`npx tsc --noEmit --incremental false`。

## 服务器配置

部署平台服务器环境变量：LOGIN_USERNAME、LOGIN_PASSWORD_HASH、APP_ORIGIN（HTTPS 网站完整来源，无末尾斜杠）、PRIVACY_CONTACT（公开展示的联系方式）。未设置账号或有效哈希时拒绝登录，旧测试密码已停用。

哈希格式：16 字节盐的十六进制字符串 + 冒号 + 64 字节 scrypt 哈希的十六进制字符串，使用 Node scrypt 默认参数。离线生成，勿把明文密码写进源码、命令历史或日志。

AI、数据库、支付密钥只放服务器环境变量。禁止 NEXT_PUBLIC_ 前缀、硬编码进页面/public、提交 Git、写日志或返回浏览器。当前未调用任何 AI 服务商。

运行 npm install、npm run dev。本地 APP_ORIGIN=http://localhost:3000。生产 npm run build 后 npm start；配置 HTTPS。生产 Cookie 强制 Secure、HttpOnly、SameSite=Strict。

## 保护措施

内置样例确认授权与非色情用途才可制作搭配板；真实换装关闭，服务器审核未配置即拒绝输出；同源校验；登录与接口限流；单次并发处理；5MB / 2000 万像素限制；真实 JPEG/PNG/WebP 解码重编码清除元数据；拒绝动画。图片只在请求内存处理，不落盘、不发送第三方。页面下载、手动清除及每 30 分钟自动清理。隐私和条款入口，基础安全响应头。

## 公网部署边界

当前适合单进程、授权账号的受限演示。会话和配额存在内存，重启重置，多实例不共享。正式 SaaS 还需要共享会话、持久化账号/配额/任务、边缘请求限流及超时、真实运营方联系方式。AI 接入需先确认服务商及隐私规则。不落盘方案无需图片存储清理任务。

这些修改必须重新部署并重启公网服务才生效。旧默认账号需立即停用。若密钥曾进入 Git、前端产物或日志，必须在供应商处撤销/轮换；删除源码不能让泄露密钥失效。代理、APM 和托管日志不要保存请求体、Cookie 或图片。本地检查不等于公网服务器审计。

## 内容安全与隐私边界（2026-10-04）

服装图片不能为空。浏览器与服务器使用透明度合成后的像素方差拦截疑似纯色、全透明或近乎空白图；此项不是衣物识别或色情检测，低对比度照片可能误判。无服装或上传失败时移除旧服装并清空结果、授权，防止继续用旧素材运行。更换任一素材后需重新授权。

色情、裸露、脱衣、性化换脸、性骚扰、未成年人照片和未经授权肖像用途被禁止。当前没有内容审核服务，也没有真实换装模型；未审核上传素材不能生成/导出，后端不会信任客户端的 reviewed/approved/builtin 标记。不得仅通过增加环境变量或移除拦截开放换装；必须实现输入、输出审核及错误时停止生成。

自上传图在本地重编码以清除源 EXIF/GPS。撤回同意、手动清除、退出账号或每 30 分钟清除素材和预览。用户下载副本不受页面清除控制。图片、请求体、Cookie 不应进入托管/APM 日志；还需在实际部署环境核验。未来 AI 图片应保留所需显式及隐式生成标识，不能沿用源元数据清理作为删除生成标识的理由。

隐私和条款页面附官方法律法规参考，说明个人信息权益、肖像授权、投诉机制和第三方处理边界。当前缺少运营方公开身份、有效隐私联系方式和投诉提交系统，不能宣称全面合规。当前成年声明不是自动年龄核验。不得接收未成年人照片。
